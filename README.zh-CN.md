# 猎魔女团钢琴 🎹

一个单文件网页钢琴小游戏，献给爱看 *KPop Demon Hunters（猎魔女团）* 的小朋友。

## 简介

直接打开 `index.html` 就能玩——不用构建、不用服务器、不用安装。屏幕上是用 three.js 渲染的 3D 钢琴键盘，下落的音符条会提示下一颗该按哪个键，玩法类似音游。这是专门给还不识谱的小朋友设计的：每个音都会标出音名，永远不用瞎猜。

## 功能特性

- **8 首猎魔女团歌曲**（金光闪闪 / Golden、汽水泡泡 / Soda Pop、看我的 / How It's Done、你的偶像 / Your Idol、终结 / Takedown、自由 / Free、这就是声音 / What It Sounds Like，以及 Takedown 的 TWICE 版本），另有**自由弹奏**模式
- **两种模式**
  - 🌱 学习模式 —— 侧边卡片显示下一颗琴键的音名，还能听 8 音示范，玩的人永远不用猜
  - ⚡ 节奏模式 —— 音符往下掉，要卡点按下，下落速度可调
- **打分反馈** —— 命中判定（带弹出动画）、连击计数，弹完一首会给出三星评价和分数总结
- **两种操作方式** —— 点/戳 3D 琴键，或用电脑键盘弹奏（从 C4 起映射两个八度）
- 完全自包含：单个 `index.html` 文件，界面为中文

## 技术栈

- 原生 JavaScript，无需构建工具
- [three.js](https://threejs.org/) r128（通过 CDN 引入）负责 3D 钢琴渲染
- Web Audio API 合成钢琴音色

## 快速开始

无需安装，直接用浏览器打开文件即可：

```bash
# 在仓库根目录执行
open index.html        # macOS
start index.html        # Windows
```

也可以本地起个静态服务器（部分浏览器对本地文件有限制时更方便）：

```bash
npx serve .
```

然后访问命令行打印出的本地地址。
